## Duel transition map

### OpenWorld to Duel writers

`DuelStarterInteractable.Interact` is the normal writer:

- rival: writes `ModuleZGameState.PendingDuelRival`, `CurrentDuelRival`, and `ModuleZDuelSessionState.RivalId`;
- context/rematch: derives progression state and writes `CurrentDuelIsRematch` plus `ModuleZDuelSessionState.IsRematch`;
- return position: rival transform plus `(0, 0, -3)`, written to `OpenWorldReturnPosition` and `ModuleZDuelSessionState.ReturnPosition`;
- transition flags: writes `ReturningFromDuel = true` and resets Duel result flags;
- scene transition: delayed call to `ModuleZSceneController.LoadDuel()`.

The region is not a separate Duel context object. It is represented indirectly by rival identity and the pre-existing `CurrentOpenWorldTheme`; the save schema persists the theme.

### Duel readers/bootstrap

- `Duel3DDebugBootstrap.Awake` always runs when its serialized `autoStartDuel3D` is true (true in source default and scene data), writes `CurrentDuelRival = debugRival`, clears result flags, optionally destroys named legacy objects, then creates `Duel3D_Runtime`.
- `Duel3DRuntimeBuilder.BuildDuel3D` reads active `ModuleZDuelSessionState` into `CurrentDuelRival`, `CurrentDuelIsRematch`, and `OpenWorldReturnPosition`.
- Immediately afterward it unconditionally writes `CurrentDuelRival = PendingDuelRival`; downstream match config/profile, HUD, audio and result messaging use legacy state.
- `Duel3DResultManager` selects the defeated rival from active session state when available, otherwise from `CurrentDuelRival`.

### Duel to OpenWorld writers/readers

- Win/loss/abandon update result flags and counters in `ModuleZGameState`.
- Win may update rival/progression unlock state through `ModuleZRivalProgression`.
- All three paths set `LastDuelResultMessage` and `PendingOpenWorldMessage`, reset rematch state, call `ModuleZSaveManager.SaveGame()`, and clear `ModuleZDuelSessionState`.
- `Duel3DResultManager.ReturnToOpenWorld` sets `ReturningFromDuel = true` and loads `OpenWorld`.
- `OpenWorldRuntimeBuilder.CreatePlayer` reads `ReturningFromDuel` and `OpenWorldReturnPosition` for spawn selection.
- `OpenWorldRuntimeBuilder.ShowPendingOpenWorldMessage` reads/clears pending/result messages and clears `ReturningFromDuel`.
