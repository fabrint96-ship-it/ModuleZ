## 10. OpenWorldSceneRoot ownership audit

Normal production ownership is:

```text
OpenWorld.unity
  -> serialized OpenWorldSceneRoot
  -> OpenWorldRuntimeBuilder.GetComponent<OpenWorldSceneRoot>()
  -> Initialize(Player, Camera, AudioListener, CameraController)
  -> Ready
```

The enabled scene contains the serialized component exactly once. Therefore normal production resolves it and does not execute the add-if-missing fallback. The fallback is conditional and cannot create a second simultaneous root after a successful `GetComponent`; it is defensive compatibility, not a second production ownership path.

Removing that fallback may be considered later but is not an F1.3 blocker.
